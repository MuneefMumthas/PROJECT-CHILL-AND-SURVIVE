# Game Description
Game Name: Chill & Survive.
This has been designed for users to experience a simple shooting game while listening to Lofi music. It has been created using Windows Forms Project (C#). The objective of this game is to eliminate as much zombies as possible before player's health runs out. At the start of the game, The player will have full health, ammos and a score of 0. The zombies will be spawned randomly accross the map and start to chase the player. When the player eliminates a zombie, the score will go up. Once the player has finished his ammos, an ammo crate will be spawned randomly for the player to collect. When the chasing zombies collide with the player, the player's health will be decreased. Finally, when the player's health reaches 0, the player is dead and the game will be over. 
     
## Features
1. The game has a menu.
2. The player can move up, down, left and right by pressing either W,A,S,D keys or the arrow keys.
3. At the start, the play has 100 health, 10 ammo and score of 0.
4. The zombies spawn randomly across the screen and start chasing the player.
5. If a zombie collide with the player, players health decreases and zombie dies.
6. The player can shoot bullets by pressing the SPACE key.
7. When the player shoots a bullet, the ammo count decreases by 1.
8. The score increases by 1 whenever a zombie dies to a bullet.
9. An ammo crate will be spawned randomly across the map when ammo hits 0.
10. When the player collects the ammo crate, the player will be granted 5 ammos.
11. When the players health goes below 1, the player is dead and game will be over.
12. The game contains sound effects.
